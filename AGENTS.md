# Agent guide

## Orientation

Retrofit electronics for Looping Louie: KiCad boards generated by Python scripts, Rust firmware on ESP-IDF, a
web UI prototype. Start with [README.md](README.md) (directories, status) and
[docs/development.md](docs/development.md) (tools, generators, router). All commands are in the justfile
(`just --list`). The repo is in English; main docs record current decisions, history goes to
[docs/decision-history.md](docs/decision-history.md).

- `hardware/scripts/`: generators (symbols, schematics, layout), router, routing score; run with KiCad's Python
  for `pcbnew` scripts (`just pcb`, `just route`, …).
- `firmware/louie-fw/`: Rust std on ESP-IDF (`just fw-build`), target directory outside the repo.
- `web/poc/`: clickable UI prototype (not scored, see docs/code-health.md).
- Generated KiCad files: never edit them by hand, change the generator and regenerate.

## Validation

```bash
just lint          # all pre-commit hooks: ruff, code health, suppressions, hardware checks
just hw-check      # ERC + DRC of both boards, generators reproduce the committed files
just fw-build      # firmware release build (devkitc-c6)
just fw-lint       # firmware rustfmt check + clippy (embedded lints, warnings are errors)
just route-check   # own router on the official board (about 1 min), after router changes
```

Behaviour of a script refactoring is shown through its outputs: byte-identical symbols and schematics, boards
compared item by item without UUIDs (KiCad orders items by random UUIDs), unchanged routing score (`just score`).

## Code health

Scored with ai-health per component (firmware, Python scripts); goal 10, i.e. no finding
([docs/code-health.md](docs/code-health.md)).

- Before every commit: `just code-health-delta` (working tree vs HEAD; the pre-commit hook runs it with
  `--staged`). Exit 1 means something got worse.
- Overview: `just code-health` (`--format json` for machine use, `-v` for all findings).
- Never remove or weaken type hints (and no cosmetic type aliases) to get rid of a smell such as Primitive
  Obsession. Real fixes are parameter objects or dataclasses where they improve the code; otherwise the finding
  stays for now, with a suppression and its reason.
- Fix smells instead of suppressing them. A suppression is per file only and needs a reason:
  `# aihealth: disable=<smell> -- <reason>` (`//` in Rust).
